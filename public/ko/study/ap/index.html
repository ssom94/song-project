AP 응용정보기술자 시험

2026年度 후기 AP를 목표로 하루 약 1시간씩 준비합니다. 고정된 분량을 반복하지 않고 실제 학습 이력, 오답, 복습 예정, 분야별 숙련도와 시험까지 남은 기간을 DB에서 확인해 그날의 학습을 자동 구성합니다.

科目A는 전 범위를 넓게 준비하고, 科目B는 정보보안(필수) + 프로그래밍 + 데이터베이스 + 정보시스템개발 + 네트워크에 집중합니다.

科目B 집중 5분야

시험 당일에는 정보보안 1문제를 필수로 풀고 나머지 네 분야를 선택하는 전략으로 준비합니다. 각 분야의 정답·오답 이력도 별도로 누적합니다.

시험 방식

방식CBT. 시험장 PC에서 문제를 보고 답하며 科目B 기술식 답안도 키보드로 입력합니다.
科目A150분 · 80문제 · 4지선다 · 전부 답변. 테크놀로지, 매니지먼트, 스트래티지 전 범위에서 출제되며 60점 이상을 목표로 합니다.
科目B150분 · 11문제 중 5문제 답변. 정보보안은 필수이며 나머지 10개 분야에서 4개를 선택합니다.
우리 선택정보보안(필수) · 프로그래밍 · 데이터베이스 · 정보시스템개발 · 네트워크
접수2027년 1월 27일 ~ 2월 16일. 科目A는 2월 6~19일, 科目B는 3월 3~15일 시행기간 중 예약합니다.

학습 방식

기본값은 하루 60분이지만 실제 분량은 DB 상태에 따라 달라집니다. 복습이 밀렸다면 신규 학습을 줄이고, 약한 주제는 다시 배정하며, 시험이 가까워지면 실전 문제 비중을 높입니다.

평상시복습 약 10분 + 개념 15분 + 科目A 25분 + 科目B 10분을 기준으로 시작합니다.
오답·복습 누적복습 대상이 많으면 최대 20분 이상으로 늘리고 신규 개념을 줄입니다.
간격 복습정답 상태에 따라 1·3·7·14·30·60일 간격으로 다시 등장합니다.
주간 누적완료 학습 7일 단위로 科目A + 科目B 혼합 누적 테스트를 배정합니다.
월간 누적30일 단위로 더 큰 누적 테스트를 실시해 다음 학습 우선순위를 조정합니다.
시험 직전科目A 45일 전부터 객관식 실전 비중을 높이고, 科目A 종료 후에는 科目B에 집중합니다.

완료한 항목, 누적시간, 일별 진행률과 오답은 DB에 남아 다음 날 학습 추천에 다시 사용됩니다.
