복잡한 한자를 획 하나씩 외우지 않고, 반복해서 등장하는 의미 부품과 실제 단어를 연결해 익힙니다.

추천 학습 순서

1. 모양·핵심 뜻

먼저 부품의 대표 모양과 한국식 훈·음을 봅니다.

2. 일본어 읽기

음독은 한자어, 훈독은 단독·활용 단어에서 확인합니다.

3. 조합으로 복원

복잡한 글자는 의미 부품과 소리 단서로 나누고 실제 단어에서 다시 합칩니다.

중요: 모든 작은 조각을 억지로 이야기로 만들 필요는 없습니다. 반복되는 부품만 익히고, 나머지는 단어 전체의 읽기와 함께 기억하는 편이 효율적입니다.
