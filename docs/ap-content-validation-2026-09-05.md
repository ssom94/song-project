## 5. 오늘의 학습 출제 로직 검증

`0059_ap_week_20261001_20261007.sql`은 과목 A 문제를 개념 sort order 순으로 정렬한 뒤 `LIMIT 10 OFFSET ...`으로 날짜별 분할한다.

이 방식의 문제점:

1. 초반 날짜에 기초이론·알고리즘 문제가 몰린다.
2. 네트워크·보안·관리·전략 문제의 혼합성이 낮다.
3. `curriculum.json`의 `balanced mixed 科目A coverage` 규칙과 구현이 일치하지 않는다.
4. generic fallback 4지선다가 실전문제처럼 선택될 수 있다.

따라서 10월 학습 시작 전, 과목 A 문제은행을 보강한 뒤 **분야 혼합 + 약점/복습 우선** 선택 방식으로 재생성하는 것이 필요하다.
