# BLOG DESIGN NOTE 12
## JLPT N1 공개 학습 이력 / JLPT N1 公開学習履歴

작성 기준일 / 作成基準日: 2026-08-31  
연계 문서 / 関連文書: `11_jlpt_n1_study_plan_ko-ja.md`

## 목적 / 目的

JLPT N1 준비를 실제로 꾸준히 진행한 기록을 사이트에 남겨, 개인 학습 관리뿐 아니라 향후 포트폴리오를 보는 채용 담당자에게도 지속적인 자기계발 과정을 보여준다.

JLPT N1 の準備を継続して行った実績をサイトに残し、個人の学習管理だけでなく、将来ポートフォリオを見る採用担当者にも継続的な自己学習の過程を示す。

## 공개 위치 / 公開場所

- `/ko/japanese/` : 최근 JLPT N1 학습 이력 요약 + 최근 8일 리스트
- `/ja/japanese/` : 最近の JLPT N1 学習履歴サマリー + 直近8日リスト
- `/ko/japanese/jlpt/` : 상세 학습 이력 최대 30일
- `/ja/japanese/jlpt/` : 詳細学習履歴 最大30日

## 공개 요약 / 公開サマリー

다음 항목을 자동 계산한다.

- 현재 연속 학습일 / 現在の連続学習日数
- 최장 연속 학습일 / 最長連続学習日数
- 총 학습일 / 総学習日数
- 누적 신규 N1 단어 / 累計新規 N1 単語
- 누적 복습 단어 / 累計復習単語
- 누적 어휘 문제 / 累計語彙問題
- 누적 문법 / 累計文法
- 누적 독해 / 累計読解

## 날짜별 리스트 / 日付別リスト

예시:

```text
2026.09.01
신규 20 · 복습 0 · 어휘 문제 15 · 문법 2 · 독해 1 · 100%

2026.09.02
신규 20 · 복습 20 · 어휘 문제 15 · 문법 2 · 독해 1 · 100%
```

일본어 화면 예시:

```text
2026.09.01
新規 20 · 復習 0 · 語彙問題 15 · 文法 2 · 読解 1 · 100%
```

## 기록 판정 / 履歴判定

단순히 `오늘의 학습 시작` 버튼을 누른 것만으로는 공개 학습일로 계산하지 않는다.

다음 중 하나 이상 실제 완료 기록이 있을 때만 학습 이력에 포함한다.

- 신규 단어 상태 평가 완료
- 복습 단어 상태 평가 완료
- 어휘 문제 완료
- 문법 완료
- 독해 완료
- 전체 세션 완료

따라서 빈 세션이나 실수로 시작한 세션이 포트폴리오 학습 이력으로 부풀려지지 않는다.

`今日の学習を開始` を押しただけでは公開学習日として数えず、実際の完了記録がある日だけ履歴に含める。

## 연속 학습 규칙 / 連続学習ルール

- 실제 학습 이력이 있는 날짜만 계산한다.
- 오늘 또는 어제까지 연속 기록이 이어진 경우 `현재 연속 학습일`을 표시한다.
- 중간에 하루라도 학습 이력이 없으면 현재 연속 기록은 끊긴다.
- 최장 연속 기록은 과거 전체 기록에서 별도로 유지한다.

## 공개 범위 / 公開範囲

공개 화면에는 학습량과 진행률만 표시한다.

공개하지 않는 정보:

- 관리자 계정 정보
- 내부 DB ID
- 오답의 상세 답변 텍스트
- 관리자 전용 메모
- 비공개 학습 콘텐츠 관리 정보

## 데이터 보존 / データ保持

학습 이력은 `japanese_jlpt_daily_sessions` 및 관련 학습 테이블의 원격 Cloudflare D1 데이터에서 계산한다.

Worker 코드 재배포와 학습 이력 데이터는 분리되어 있으므로 정상적인 코드 배포만으로 기존 학습 기록이 삭제되지 않는다.

장기 학습 기록은 로컬 `wrangler dev` DB가 아니라 원격 `song-project-db`를 기준으로 한다.
