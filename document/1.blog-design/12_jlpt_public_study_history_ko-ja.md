## 1. 목적 / 目的

JLPT N1 준비 과정 자체를 장기 기록으로 남긴다. 개인 학습 관리뿐 아니라 향후 포트폴리오를 확인하는 채용 담당자에게도 꾸준한 자기계발 이력을 보여주는 것이 목적이다.

JLPT N1 の準備過程そのものを長期記録として残す。個人の学習管理だけでなく、将来ポートフォリオを見る採用担当者にも継続的な自己学習を示す。

## 2. 공개 학습 이력 / 公開学習履歴

공개 화면에서는 실제 수행한 학습만 날짜별 리스트로 표시한다.

예:

```text
2026.09.02  완료 · 100%
스케줄 5/5 · 복습 20/20 · 신규 단어 20/20 · 어휘 문제 15/15 · 문법 2/2 · 독해 1/1

2026.09.03  학습 중 · 68%
스케줄 3/5 · 복습 20/20 · 신규 단어 20/20 · 어휘 문제 15/15 · 문법 0/2 · 독해 0/1
```

복습 대상이 없는 날처럼 목표량이 0인 영역은 당일 스케줄 개수 계산에서 제외한다.

### 공개 요약

- 현재 연속 학습일 / 現在の連続学習日数
- 최장 연속 학습일 / 最長連続学習日数
- 총 실제 학습일 / 総実学習日数
- 누적 신규 N1 단어 / 累計新規 N1 単語
- 날짜별 스케줄 완료 개수 / 日別予定完了数
- 날짜별 신규·복습·어휘 문제·문법·독해 완료량

단순히 `오늘의 학습 시작`만 누른 빈 세션은 공개 학습 이력으로 계산하지 않는다. 실제 완료량이 하나 이상 있거나 세션 자체가 완료된 날짜만 학습 기록으로 인정한다.

## 3. 메인 홈 학습 이력 / ポートフォリオホームの学習履歴

메인 포트폴리오 홈의 JLPT 영역 근처에 공개 학습 이력 카드를 둔다.

- 최근 학습 이력을 리스트 형식으로 확인
- `더 보기 / さらに表示`로 과거 기록 확장
- 한국어/일본어 전환 대응
- JLPT 전용 학습 화면으로 이동 링크 제공

일본어 학습 홈에서도 동일한 공개 이력을 확인할 수 있다.

## 4. 오늘의 학습 플로팅 체크리스트 / 今日の学習フローティングチェックリスト

사이트의 public dashboard 화면에서 오늘 해야 할 JLPT N1 학습을 작은 플로팅 카드로 계속 확인할 수 있게 한다.

### 기본 위치

- 데스크톱: 화면 우측 상단 영역
- 자동 이동 없음
- 제목 영역을 드래그해서 원하는 위치로 이동 가능
- 이동 위치는 `localStorage`에 저장하여 다음 방문에도 유지
- 위치 초기화 버튼 제공
- 접기/펼치기 지원
- 모바일에서는 우측/하단 영역에서 화면을 과도하게 가리지 않도록 표시

### 체크리스트 항목

```text
복습 어휘
신규 어휘
어휘 문제
문법
독해
```

당일 목표가 0인 항목은 전체 스케줄 개수 계산에서 제외한다.

### 완료 표시

- 완료 여부는 DB의 실제 당일 진행량과 목표량으로 판정한다.
- `완료량 >= 목표량`이면 체크됨.
- 완료 항목은 회색/저채도 배경, 낮은 opacity, 취소선으로 남은 항목과 구분한다.
- 신규/복습 어휘는 각 단어의 학습 상태 지정 결과로 자동 누적한다.
- 어휘 문제·문법·독해는 관리자 로그인 상태에서 체크하여 완료 처리할 수 있으며 DB의 당일 진행량에 반영한다.
- 변경 후 플로팅 카드와 공개 학습 이력을 즉시 다시 불러온다.

### 표시 예

```text
JLPT N1 · TODAY
오늘의 학습
3 / 5 스케줄 완료

☑ 복습 어휘       20 / 20
☑ 신규 어휘       20 / 20
☑ 어휘 문제       15 / 15
☐ 문법             0 / 2
☐ 독해             0 / 1
```

## 5. 데이터 신뢰성 / データ信頼性

포트폴리오에 공개되는 학습 이력은 화면용 임시 값이 아니라 원격 Cloudflare D1 `song-project-db`의 날짜별 JLPT 학습 세션을 기준으로 계산한다.

Worker 코드 재배포는 D1 학습 기록을 자동 삭제하지 않는다. 장기 학습 기록은 로컬 Wrangler DB가 아니라 원격 D1을 기준으로 한다.
