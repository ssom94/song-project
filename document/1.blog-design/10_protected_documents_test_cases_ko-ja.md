## 3. 공개 코드 입력 / 公開コード入力

| ID | 테스트 / テスト | 기대 결과 / 期待結果 |
|---|---|---|
| PACC-01 | 한국어 스킬시트에서 상세판 진입 | `/protected/?lang=ko`로 이동하고 한국어가 선택된다 |
| PACC-02 | 일본어 스킬시트에서 상세판 진입 | `/protected/?lang=ja`로 이동하고 일본어가 선택된다 |

| PACC-04 | 3자리 이하 제출 | 클라이언트에서 차단된다 |
| PACC-05 | 올바른 JA 코드 + JA 선택 | 인증 성공 |
| PACC-06 | 올바른 JA 코드 + KO 선택 | 인증 실패 |
| PACC-07 | 올바른 KO 코드 + KO 선택 | 인증 성공 |
| PACC-08 | 동일 IP에서 15분 내 5회 실패 | 이후 요청은 429로 15분 잠금 |
| PACC-09 | 인증 성공 | HttpOnly 보호문서 세션 쿠키가 생성된다 |
| PACC-10 | 인증 성공 후 | 선택 언어가 유지된 보호 뷰어로 이동한다 |

## 참고 / 注意

- 4자리 숫자 코드는 가능한 조합이 10,000개뿐이므로 실패 횟수 제한을 필수로 함께 사용한다.
- 日本語・韓国語の原本バージョンとアクセスコードは別々に管理する。
- Excel → PDF/PNG 변환 및 실제 뷰어 페이지 표시는 후속 변환 파이프라인 테스트에서 별도로 확인한다.
