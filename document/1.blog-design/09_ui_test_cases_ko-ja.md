## 테스트 데이터 / テストデータ

- Seed: `seeds/test_data.sql`
- 테스트 예약 ID: `900000001+`
- 로컬 D1 적용: `npx wrangler d1 execute song-project-db --local --file=./seeds/test_data.sql`
- 원격 D1 적용은 최종 테스트 직전에만 수행: `npx wrangler d1 execute song-project-db --remote --file=./seeds/test_data.sql`
- Seed는 고정 ID + `INSERT OR IGNORE` 방식으로 중복 실행 가능하게 구성한다.

## 테스트 완료 기준 / 完了基準

1. 모든 Critical 기능 테스트 PASS
2. PC / Tablet / Mobile 레이아웃 중단 없음
3. 공개 API가 draft/private/pending을 노출하지 않음
4. 관리자 mutation은 인증 + same-origin 정책 유지
5. JA/KO 양쪽에서 핵심 화면의 의미와 링크가 일치
6. 테스트 seed를 다시 실행해도 중복/제약 오류가 발생하지 않음
