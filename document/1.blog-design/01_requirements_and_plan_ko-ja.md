# BLOG DESIGN NOTE 01
## Cloudflare 기반 개인 블로그 / Cloudflareベース 個人ブログ

작성 기준일 / 作成基準日: 2026-08-29

## 1. 프로젝트 목표 / プロジェクト目標

### 한국어
Cloudflare를 중심으로 장기간 운영할 개인 개발 블로그를 구축한다. 블로그 글은 관리자 본인만 작성하며, 일반 방문자는 로그인이나 회원가입 없이 콘텐츠를 열람하고 댓글을 작성할 수 있다. 초기에는 복잡한 회원 시스템을 만들지 않고 운영에 필요한 기능을 우선 구현한다.

### 日本語
Cloudflareを中心に、長期間運用できる個人開発ブログを構築する。記事の作成は管理者本人のみが行い、一般訪問者はログインや会員登録なしで記事閲覧とコメント投稿ができる。初期段階では複雑な会員機能を持たず、運用に必要な機能を優先して実装する。

## 2. 확정된 기능 요구사항 / 確定した機能要件

- 관리자 1명만 로그인, 글 작성 권한은 관리자에게만 부여  
  管理者は1名のみ。記事の作成権限は管理者だけに付与
- 게시글 작성/수정/삭제, 제목/본문/대표 이미지/카테고리/태그/작성일/수정일/조회수  
  記事の作成・編集・削除、タイトル/本文/アイキャッチ画像/カテゴリ/タグ/作成日/更新日/閲覧数
- 방문자는 회원가입/로그인 없이 게시글 열람, 검색, 카테고리/태그 조회  
  訪問者は会員登録・ログインなしで記事閲覧、検索、カテゴリ/タグ閲覧
- 비회원 댓글 작성 가능: 닉네임, 비밀번호, 내용, 작성일 저장  
  非会員コメント: ニックネーム、パスワード、本文、作成日時を保存
- 댓글 작성 시 실제 접속 IP 저장. 관리자만 확인 가능, 공개 화면에는 미노출  
  コメント投稿時に接続元IPを保存。管理者のみ確認可能で公開画面には表示しない
- 카테고리와 태그는 각각 별도 관리자 페이지에서 추가/수정/삭제  
  カテゴリとタグはそれぞれ専用管理画面で追加・編集・削除
- 대표 이미지와 본문 이미지 업로드  
  アイキャッチ画像・本文画像アップロード
- 관리자에서 댓글 확인/삭제, IP 기반 스팸 대응 확장 가능  
  管理画面でコメント確認/削除、IPを利用したスパム対策へ拡張可能

## 3. 관리자 화면 / 管理画面

- `/admin` - 대시보드 / ダッシュボード
- `/admin/posts` - 게시글 목록 / 記事一覧
- `/admin/posts/new` - 새 글 작성 / 新規記事作成
- `/admin/posts/:id/edit` - 게시글 수정 / 記事編集
- `/admin/comments` - 댓글 관리 + IP 확인 / コメント管理 + IP確認
- `/admin/categories` - 카테고리 관리 / カテゴリ管理
- `/admin/tags` - 태그 관리 / タグ管理

## 4. 방문자 화면 / 公開画面

- `/` - 홈 / ホーム
- `/posts` - 게시글 목록 / 記事一覧
- `/posts/:slug` - 게시글 상세 + 댓글 / 記事詳細 + コメント
- `/categories/:slug` - 카테고리별 게시글 / カテゴリ別記事
- `/tags/:slug` - 태그별 게시글 / タグ別記事
- `/search` - 검색 결과 / 検索結果

## 5. Cloudflare 시스템 구조 / Cloudflareシステム構成

- Cloudflare Workers: 화면 + API / Frontend + API
- Cloudflare D1: 게시글, 댓글, 카테고리, 태그, IP 등 구조화 데이터
- Cloudflare R2: 대표 이미지와 본문 이미지 파일
- GitHub: 소스코드와 설계 문서 버전 관리
- Cloudflare Builds: `main` 브랜치 push 시 자동 배포

## 6. 초기 데이터 모델 / 初期データモデル

- `admins` - 관리자 인증 / 管理者認証
- `posts` - 게시글 / 記事
- `categories` - 카테고리 / カテゴリ
- `tags` - 태그 / タグ
- `post_tags` - 게시글-태그 다대다 연결 / 記事-タグ多対多
- `comments` - 비회원 댓글, 비밀번호 해시, IP / 非会員コメント、PWハッシュ、IP

### IP 저장 원칙 / IP保存方針
비회원 댓글의 접속 IP는 관리자만 확인하고 공개 화면에는 노출하지 않는다. 스팸 방지와 운영 목적에 필요한 범위에서 사용하며, 실제 운영 전 개인정보 안내와 보관 기간을 별도로 정한다.

非会員コメントの接続元IPは管理者のみ確認可能とし、公開画面には表示しない。スパム対策・運用目的の必要範囲に限定し、本番公開前にプライバシー案内と保存期間を定める。

## 7. 개발 순서 / 開発順序

1. 요구사항 확정 / 要件確定
2. D1 데이터 모델 설계 / D1データモデル設計
3. D1 생성 및 migration 구성 / D1作成・migration構成
4. 관리자 인증 설계 / 管理者認証設計
5. 게시글 CRUD API + 관리자 게시글 화면 / 記事CRUD API + 管理画面
6. 카테고리/태그 관리 / カテゴリ・タグ管理
7. R2 이미지 업로드 / R2画像アップロード
8. 방문자용 게시글 목록/상세/검색 / 公開記事一覧・詳細・検索
9. 비회원 댓글 + IP 저장 + 비밀번호 해시 / 非会員コメント + IP保存 + PWハッシュ
10. 댓글 관리 + Turnstile/Rate Limit / コメント管理 + スパム対策
11. SEO, sitemap, 백업, 로그, 운영 문서 / SEO、sitemap、バックアップ、ログ、運用文書
